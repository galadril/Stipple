# Third-party notices

Stipple is licensed GPL-3.0-or-later. See [`LICENSE`](LICENSE).

Blueprint §5 requires that every imported dependency record its source, version,
licence, reason for inclusion and redistribution status. This file is the
register.

## Runtime dependencies

| Component | Version | Licence | Why | Redistributed |
|---|---|---|---|---|
| [Berry](https://github.com/berry-lang/berry) | pinned at `4bf803a511ed` (2026-09-24) | MIT | The scripting language. Under 40 KiB of code, ANSI C99, and the language existing AWTRIX NG scripts are written in — so those scripts run rather than being rewritten. | Yes, vendored in `third_party/berry/` |

**`stipple_core` itself still has none.** Berry is a separate target
(`stipple_berry`) that core does not link, so a build without scripting is the
same core it always was. That boundary is the reason the dependency was
acceptable at all.

Berry's own constant tables are generated by its `coc` tool and **vendored**
rather than generated during our build, so building Stipple needs no Python
and no network. `firmware/script/berry_conf.h` records how to regenerate them.
