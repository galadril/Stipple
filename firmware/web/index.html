      Backup

      Downloads every setting as a file. The MQTT password is not in it — the device never gives it back, to anyone — so it has to be typed in again after a restore.

      Reset

      Puts settings back to their defaults. The device keeps its name, so it is still the one you were looking at.

      Restart

      Settings are saved as you change them, so a restart loses nothing.

      Firmware

      There is no firmware upload here, and that is deliberate rather than unfinished. Installing to flash needs a restore image captured from this exact device and a demonstrated way to put it back, and the second does not exist yet — this hardware has no dd, flashcp or nandwrite. A button that wrote flash without one would be a brick waiting for a bad day. See ADR 0008.
